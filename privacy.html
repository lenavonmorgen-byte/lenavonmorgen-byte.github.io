Privacy Policy

Last updated: 14 October 2026

What this app is

TubeYou Uploader is a private tool run by the owner of the YouTube channel @now.u.know.official and the TikTok account @now.u.know.official. It uploads the owner's own videos through the YouTube Data API and the TikTok Content Posting API. It is not offered to the public.

Data accessed

From Google, the app requests only the OAuth scope https://www.googleapis.com/auth/youtube.upload, which allows uploading videos to the signed-in YouTube channel. It does not read, store or share any other Google user data.

From TikTok, the app requests only the scopes user.info.basic (to identify the signed-in account and show its posting options) and video.publish (to post videos to that account). It does not read, store or share any other TikTok user data.

Storage

The OAuth access and refresh tokens are stored only on the owner's own computer, so that uploads can run automatically. No passwords are stored. No data is sent to any server other than Google's and TikTok's.

Sharing

No user data is sold, shared or transferred to third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions (Google) and in the TikTok app under Settings and privacy → Security → Manage app permissions (TikTok).

Google API Services

TubeYou Uploader uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service. See also the Google Privacy Policy. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

TikTok

Use of TikTok through this app is also subject to the TikTok Terms of Service and the TikTok Privacy Policy.
