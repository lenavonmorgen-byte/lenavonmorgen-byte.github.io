Privacy Policy

Last updated: 14 October 2026

What this app is

TubeYou Uploader is a private tool run by the owner of the YouTube channel @now.u.know.official. It uploads the channel's own videos through the YouTube Data API. It is not offered to the public.

Data accessed

The app requests only the Google OAuth scope https://www.googleapis.com/auth/youtube.upload, which allows uploading videos to the signed-in YouTube channel. It does not read, store or share any other Google user data.

Storage

The OAuth access and refresh token is stored only on the owner's own computer, so that uploads can run automatically. No passwords are stored. No data is sent to any server other than Google's.

Sharing

No user data is sold, shared or transferred to third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

TubeYou Uploader uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service. See also the Google Privacy Policy. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
